欢迎来到我的博客

2026 年 8 月 8 日 · 约 1 分钟阅读 随笔建站

欢迎来到我的小站！🎉

这是我搭建个人主页后写下的第一篇文章。之后我会在这里分享：

  • 技术笔记：Python、Web 开发、Git 等
  • 学习心得：读书、课程、项目复盘
  • 生活记录：一些值得记住的瞬间

这个网站是怎么工作的？

这个站点是纯静态网站，通过 build.py 把 Markdown 文章转换成 HTML 页面，再托管在 GitHub Pages 上，完全免费、不需要服务器。

如果你对搭建过程感兴趣，可以看看我写的《用 GitHub Pages 搭建个人主页》。

如何发布一篇新文章？

步骤非常简单：

  1. 在 posts/ 目录下新建一个 Markdown 文件
  2. 在文件开头写上标题、日期和标签
  3. 运行 python build.py 生成页面
  4. 用 git push 推送到 GitHub

代码块长这样：

python build.py

写起来只需要会 Markdown 就行，非常轻量。我们下一篇见！👋
