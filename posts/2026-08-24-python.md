# 命令行调试基本命令（pdb）

## 代码中加断点的调试

在代码相应需要打断点的位置加入``breakpoint()``代码，然后在命令行输入运行命令，自动进入调试（pdb）模式。

`>`符号指向的是当前代码所在的位置（框架，函数等）

`->`符号指向的即是下一行要运行的代码

## 代码中不加断点的直接调试

`python -m pdb 文件名`

1. 开始运行程序，运行后会在第一个能停下来的地方停下来
2. 开始调试后使用`b 行号`或`break 行号`设置断点进行调试。`break`后不加参数则是列出所有的断点，也可以`b`后加函数名表示断点设置在函数的位置，运行到函数中自动停下

## 检视程序当前状态的命令

1. 打印变量名称：`p 变量名`（p即为print），打印的内容可以是任何一个合法的python表达式
  1. 打印变量时先从当前帧的局部变量开始找，可以通过`u`或`up`改变当前帧（去到当前帧的上一层
  2. 使用`d`或`down`往下调整当前帧
2. 打印调用栈（调用层级）：`w`
3. 查看当前位置附近的源代码：`l`或`list`，默认打印当前行前后11行代码，再输入`l`再向下输出11行，输入`l.`返回当前行代码
4. 查看当前函数的全部代码：`ll`或`longlst`

## 控制程序的运行

1. `n`或`next`运行一行程序，当有函数调用时使用n会直接运行完整个函数
2. `s`或`step`进入函数单步运行程序。next和step只有在函数调用时是不一样的作用
3. 在函数即将返回时输入`retval`获取到返回值的数值
4. 程序继续运行直到特定条件发生：`until 参数`，条件可以是行数，意思是运行到对应的行数停止，可以用来跳出循环。
5. 运行到函数返回之前：`r`或`Return`
6. 程序继续正常运行不再继续调试：`c`或`continue`
7. 调试完成从debug中直接退出：`q`或`quit`
8. 删除断点：`clear 断点编号`。不加编号则删除所有断点

# 使用IDE提供的调试功能调试（以vscode为例）

## 使用`launch.json`配置

1. 打开项目文件夹，在左侧“运行与调试”中点击“创建一个launch.json文件”
2. 选择"Python"
3. 选择"Python文件"
4. 配置`launch.json`文件：
  ```json
  {
      "version": "0.2.0",
      "configurations": [
          
          {
              "name": "Python 调试程序: 包含参数的当前文件",
              "type": "debugpy",
              "request": "launch",
              "program": "${workspaceFolder}/main.py",   //指定主程序文件
              "args":[
                  "-s", "/path/to/s",
                  "-m", "/path/to/m",],    //指定运行参数
              "console": "integratedTerminal",
              "justMyCode": true,    //指定是否仅调试自己的代码（是否包含库代码）
              "env": {"PYTHONPATH": "${workspaceFolder}"},  //设置环境变量
              "cwd": "${workspaceFolder}"  //设置工作目录
          }
      ]
  }
  ```
5. 参数解释：
  - `program`: 指定项目的主入口文件
  - `args`: 设置命令行参数，每个参数用引号括起并用逗号分隔
  - `cwd`: 设置工作目录
  - `console`: 设置在集成终端中运行
6. 设置断点（可以右键断点给其设置条件，合法的python表达式均可）
7. 启动调试，`F5`或”运行与调试“界面上方点击开始调试
8. “调试控制台”可以打印表达式的值
