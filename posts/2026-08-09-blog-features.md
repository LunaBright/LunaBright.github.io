这篇文章用来演示本站博客支持的各种写作语法，方便你在后台写文章时直接参考。

## Markdown 表格

表格用竖线语法书写，第一行是表头，第二行是分隔线：


| 功能 | 语法 | 示例 |
| --- | -------------------------------------------------------------------------------------------------- | -------- |
| 表格 | ` | 列 | 列 | ` | 本表格 |
| 公式 | `$...$` | $E=mc^2$ |
| 图片 | `![说明](地址)` | 见下文 |
| 粗体 | `**文字**` | **加粗** |


## LaTeX 公式

行内公式用单个美元符号包裹：质能方程 $E=mc^2$，勾股定理 $a^2 + b^2 = c^2$。

块级公式用两个美元符号：

$$
\int_{-\infty}^{+\infty} e^{-x^2}dx = \sqrt{\pi}
$$

## 分类与标签

每篇文章可以设置一个**分类**（默认提供：技术 / 生活 / 随笔）和任意多个**标签**。博客页顶部可以按分类、标签筛选，也可以用右上角的搜索框搜索标题和正文。

> 提示：图片尺寸支持百分比或像素值，例如 `width:320px`；对齐支持 `left` / `center` / `right`。
